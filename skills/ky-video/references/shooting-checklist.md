# 拍摄清单（发给用户）

- [ ] 拍正片前先拍 10 秒测试样片发给我，确认比例、帧率、背景
- [ ] 横屏 16:9，4K，30 帧；背景和壁纸定好后整期不再改
- [ ] 人坐在画面偏右，左边留出空间放动画
- [ ] 室内光线稳定，不要背光
- [ ] **说错了 → 停 2 秒 → 从整句开头重说**，不要从半句接着说
- [ ] 每句话说完稍停半秒再说下一句，方便下刀
- [ ] 结尾说完后安静 2 秒再停止录制
- [ ] **单独拍 2–3 张封面照**（同一机位、竖着拍或留足上下空间）：表情要有情绪（惊讶、笑、皱眉、指向镜头、拿道具），头顶和胸口留出放字的位置
- [ ] 导出原片后直接告诉我路径；原片自己留一份
