# 封面版式

两套版式，在 `src/video/covers.tsx` 里都已注册，用哪套就把对应 id 写进 `project.json` 的 `covers`。

| 版式 | Still id | 照片 | 气质 |
|---|---|---|---|
| suspense（风格包自带） | `cover-169 / cover-43 / cover-34` | 正片截帧（`frames`） | 跟视频风格一致，划掉的常识 + 问号框 |
| bigtext（通用，`src/engine/BigTextCover.tsx`） | `bigtext-34 / bigtext-916 / bigtext-43 / bigtext-169` | 专门拍的封面照最好，截帧也能用 | 真人大头 + 上下粗描边大字，主页排在一起有系列感 |

## 大字封面写法

- **上行**：约 4 个字，白字黑描边，字号按字数自动撑满宽度。ASCII 字母按 0.6 个字算（「AI时代」≈ 3.2 个字）。
- **副标题**（可选）：一行小字，放在下行上方，补充信息，比如「AI几秒就能给你」。
- **下行**：约 4 个字，最大最醒目；`accent` 选一种颜色（`lime` 黄绿渐变 / `gold` / `white`），**每期都用同一种**，它就是系列的识别标志。
- 不超过 5 个字一行；字多了字号会变小，缩略图上看不清。
- 只抛问题，不说答案（例：上「十个方案」/ 副「AI几秒就能给你」/ 下「你选哪个」）。
- 照片：脸放在中间三分之一，头顶和胸口要留空。截图偏了用 `focus: [x, y]`（0–1）调整裁切中心。
- `tag` 可选的小角标（比如期数、系列名），默认不加；不默认写「由 AI 制作」。

## 尺寸

- 先看 3:4：抖音、小红书、视频号主页都显示 3:4（见 `platforms.md`）。
- 4:3 / 16:9 横版沿用 3:4 的字号（文字列宽 = 高度 × 0.75）。横版照片用 `photoWide`（一张横的照片，比如正片截帧 `cover_calm.png`）；不给就从竖照片裁，脸会被放得太大、被字挡住。
- 9:16 用作视频首帧或全屏封面。

## 检查

出完缩到约 300px 宽看：字能不能一眼读出来、有没有挡住眼睛和嘴、四个角的平台角标会不会压住关键字。
