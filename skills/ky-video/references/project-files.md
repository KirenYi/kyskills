# 项目文件写法

完整真实示例：`assets/examples/taste/`

## project.json

| 字段 | 说明 |
|---|---|
| `title` | 视频标题，用于输出文件名 |
| `source` | 原片路径（只读） |
| `style` | 风格包名 |
| `face` | 人脸中心在 1920×1080 画面中的坐标，决定放大中心、C/D 版式裁切、口型检测区域。拿一帧截图量一下 |
| `frames` | 封面用的截图：`{"文件名.png": 秒数}`，prep 时从中间文件截到 public/ |
| `covers` | 封面 Still id → 导出文件名列表（每个平台一份） |

## edl.json（剪辑表）

```json
{
  "drop_first": [128.088],
  "pads": [0.08, 0.10],
  "items": [
    ["seg", 120.848, 126.188, "hook", "A", "钩子那句话"],
    ["card", "title", 1.8, "E"],
    ["seg", 0.728, 4.208, "1", "D", "字幕文本，按稿子写正确的字"]
  ]
}
```

- 时间 = `work/transcript.md` 里的秒数（中间文件时间），不需要很精确，build 会按声音能量自动收紧。
- `seg`：`[开始, 结束, 镜头名, 版式, 字幕]`。前一条的结束等于后一条的开始时，会被当作同一条连续镜头。
- `card`：纯卡片，`[镜头名, 秒数, "E"]`，画面是风格底色加静音。
- 镜头名 `hook` 和 `title` 是保留名：hook = 开头钩子片段，title = 钩子后的标题卡。
- `drop_first`：这一段的第一个发声要删掉（结巴，比如"十…十版"），填该 seg 的开始时间。
- `pads`：句前、句后的留白（秒）。默认 0.08 / 0.10。
- 句尾带出了下一句的词（比如"一整天…现在"）会自动在能量最低点下刀，但要用 check.py 确认没切掉最后一个字。

### 版式 A–E

| 版式 | 画面 | 适合 |
|---|---|---|
| A | 全屏口播（自动在 1.0 / 1.18 两档放大之间切换，像双机位） | 观点、情绪、过渡句 |
| B | 全屏口播，左侧叠文字动画 | 关键词、短句、金句 |
| C | 左侧大动画，人像在右侧卡片里 | 图解、对比、层级 |
| D | 全屏动画，人像在右下画中画 | 引用、例子、海报 |
| E | 纯全屏卡片（人像隐藏） | 章节卡、需要专心看的画面 |

## src/video/scenes.tsx

```tsx
export const VIS: [string, string, Render][] = [
  ['9', '9', (p) => <St.NotEqual {...p} left="品味" right="贵" key2="贵" />],   // 从镜头 9 到镜头 9
  ['11', '16', (p) => <V.Pyramid {...p} />],                                   // 跨镜头 11–16
];
export const SFX_MAP = {
  '9': (p) => [[0, 'pop'], [p.kw('贵', 12) + 10, 'strike']],   // 帧偏移 + 音效名
};
export const HOOK = {variants: [{lines: [...], hi: '高亮词'}], stamp: '答案词', payKey: '说出答案的词', defaultVariant: 0};
```

- `p.kw('词', 兜底帧)`：这个词在该段里说出来的帧（相对段首）。动画和音效都挂在这上面，保证跟人声同步。
- `p.cues[i]`：段内第 i 个镜头开始的帧。
- 音效：pop（弹出）、tick（逐条出现）、ding（结论）、whoosh（转场）、strike（划掉）、impact（重音）、type（打字）。克制使用，只放在关键处。
- `St.*` 是风格包组件，`V.*` 是本期专属组件（写在 custom.tsx）。

## 渲染 id

- `main`：成片
- `hook-0`、`hook-1` …：钩子预览
- `cover-169`、`cover-43`、`cover-34`：封面
