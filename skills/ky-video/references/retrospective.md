# 口播 + AI 动画视频 · 复盘手册

来源：作者第 1 期视频《品味》的制作复盘（2026-11 发布，成片 4:34，4K）
用途：下次做视频前先读一遍。坑不再踩，做对的直接复用。

---

## 一、整体流程（这次实际跑通的顺序）

1. **聊选题** → 定必须回答的问题 + 拓展点
2. **写口播稿 + 分镜表**（每句对应一个画面：口播 / 半屏动画 / 全屏卡片）
3. **出 3 张风格样图** → 选定视觉风格
4. **出 10 秒动态样片** → 确认动画节奏
5. **你拍摄**（先拍测试样片确认比例、帧率、背景）
6. **我剪辑**：转写 → 选最后一遍 → 精剪停顿 → 挂动画 → 字幕 → 音效
7. **出开头钩子 3 个版本** → 你选
8. **你看整片提意见** → 改 2～3 轮
9. **封面 3 款 → 选 1 款 → 出全平台尺寸**，同步写标题和简介
10. **导出 4K + 发布包**

## 二、吃过的亏（以后不再犯）

### 1. 口型对不上 ⚠️ 最重要
- **原因**：开拍 App 录出来的是**可变帧率（VFR）**视频，按时间点直接剪，每一刀都会有几帧偏差，越剪越歪。原片音频中途还可能有时间戳跳变（这期在约 4:33 处跳了 0.1 秒）。
- **做法**：拿到原片后**第一步**先完整解码一遍，转成固定 30 帧的中间文件（mezz.mp4 + mezz.wav），之后**按帧号剪画面、按采样点剪声音**。语音转写也用中间文件的音频来跑，这样所有时间都在同一个时间基准上。
- **验证**：导出前用"嘴部画面运动 vs 声音音量"做相关性检查，偏差 0 帧才算过。

### 2. 动画比人声先出来
- **原因**：语音识别（whisper）给的每个字的时间不准，会把停顿算进字里，误差可达几秒。
- **做法**：
  - 句子的真实起止点用**声音能量检测**（10ms 一格）来定，不信 whisper 的边界。阈值要用**相对值**（全片音量 95 分位的 9.2%），写死绝对值的话，换了麦克风或音量就会多剪或少剪（做 Skill 回归时踩到的）。
  - 动画**挂在关键词上**触发（例如说到"贵"字时弹出），不按句子开头。
  - 头部留 0.06 秒，尾部留 0.12 秒。

### 3. 卡顿、气口、口头残留
- 句中停顿超过 0.3 秒 → 压缩到约 0.2 秒。
- 结巴（"十…十版"）→ 删掉第一个片段。
- 句尾多出来的词（"一整天…现在"）→ 在句尾后找音量最低点下刀。
- **改完要用 whisper 再听一遍切口**，第一次修"现在"时把"天"字也切掉了。

### 4. BGM
- 用代码合成的钢琴不好听，这期最终不加 BGM。
- **待办：下次拍视频时专门测试、优化 BGM**（用真实曲库，说话时自动压低音量）。

### 5. 开头钩子不够抓人
- 第一版只是把正片片段复制到开头，不够吸引人。
- **做法**：钩子片段上叠**大字标题**，必须讲观众在意的东西或反常识的说法，并和 AI 相关（这次选的是"AI 时代最值钱的，不是会用 AI"）。

### 6. 封面和标题说出了答案
- 封面写出"是品味"，观众就没有理由点进来了。
- **原则**：封面和标题**只抛问题，不给答案**，答案留给简介和正片。

### 7. 平台尺寸搞错
- 抖音横封面是 **4:3**，不是 16:9。
- 各平台尺寸：
  - 抖音：横封面 4:3 + 竖封面 3:4
  - 视频号：个人主页卡片 3:4 + 分享卡片 4:3
  - B 站：16:9 + 4:3
  - YouTube：16:9

### 8. 传错文件
- 中间文件（cut.mp4 / cut1440.mp4，不带动画）容易被误传。
- **做法**：最后统一整理成 **发布包文件夹**，只传里面的东西。

### 9. 其他小坑
- 动画盖住了人脸 → 全屏动画时人像要缩到画中画，并放在动画之上。
- 竖版封面渐变遮住头发 → 人像往下移，渐变缩短。
- 本机 ffmpeg 没有 drawtext → 文字一律在 Remotion 里做。

## 三、做对的地方（直接复用）

- **视觉风格**：极简杂志风（米白 #F7F5F0 / 黑 / 红 #D23C22，宋体标题 + 苹方正文）。
- **5 种版式自动切换**：A 全屏口播 / B 口播放大 / C 左动画右人像 / D 全屏动画 + 右下画中画 / E 纯卡片。人脸始终不被挡。
- **关键词音效**：pop、tick、ding、whoosh、strike、impact、打字声，只在关键处出现，平时克制。
- **给选项让你挑**：风格、钩子、封面都出 3 版，选择权在你，效率高。
- **重拍处理规则**：同一句拍了几遍，保留**最后一遍**。
- **响度统一**：成片 -16 LUFS，各平台直接可用。
- **4K 导出**：用 4K 中间文件 + Remotion 2 倍渲染，导出后和 1080p 版逐帧比对一致。
- **定位融入内容**：片中、封面角标、简介都写"动画由 AI 制作"，并引导合作和咨询私信。

## 四、你拍摄时的习惯清单（能大幅省剪辑时间）

- [ ] 拍正片前先拍 10 秒测试样片发给我，确认比例、帧率和背景
- [ ] 横屏 16:9，4K，背景和壁纸定好后不再改
- [ ] **说错了 → 停 2 秒 → 从整句开头重说**，不要从半句接着说
- [ ] 每句话说完稍停半秒再说下一句（方便下刀）
- [ ] 结尾说完后安静 2 秒再停止录制
- [ ] 原片保留，导出后直接给我路径

## 五、默认偏好（用户另有要求时以用户为准）

- 动画必须**跟着人声同时出现**，不能提前
- 节奏要紧凑，卡顿和气口都要剪干净
- 画面不平淡，关键点要有点缀音效
- 封面要反差、制造悬念，不剧透
- 不用先给粗剪，直接出完整版看效果
