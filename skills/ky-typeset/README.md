# ky-typeset

把 Markdown 排版成带样式的单页 HTML，复制后可直接粘贴进公众号、知乎、Substack、Medium、邮件等编辑器。19 套样式。

Typeset Markdown into a styled single-page HTML you can paste into WeChat, Substack, Medium, email newsletters and other rich-text editors. 19 styles.

```text
/ky-typeset
```

```bash
./scripts/install-links.sh ky-typeset
```

原名 `ky-mphtml`，旧命令仍可触发。Formerly `ky-mphtml`.
