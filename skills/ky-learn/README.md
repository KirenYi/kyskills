# ky-learn

带本地连续状态的交互式学习 Skill。导师负责课程路线、掌握检验和紧凑沉淀。

## 状态

`0.1.0-preview.1`：公开预览。结构与静态协议已验证，连续学习体验和长期压缩效果仍需更多真实使用。

## 本地数据

默认写入 `~/.ky-learn/`：

- `learning-index.md`：当前学习主题与接入点
- `subjects/`：每个长期主题一份状态文件
- `notes/`：仅在有高信号内容时生成的整理笔记

可通过 `KY_LEARN_HOME` 指定其他绝对路径。Skill 不会把状态写入当前项目，也不会上传用户学习记录。

## 使用

安装 `ky-skills` 后，可以说：

- “用 ky-learn 带我系统学习经济学。”
- “继续学习。”
- “考考我上次掌握得怎么样。”
- “结束学习。”
