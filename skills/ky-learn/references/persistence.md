# 学习沉淀协议

## 状态根目录

开始任何读取或写入前，运行：

```bash
python3 "$SKILL_ROOT/scripts/state_root.py" --init --json
```

返回路径是本次操作唯一允许的状态根目录。不能初始化、目录不存在或实际写入失败时停止保存并说明原因；不得把当前工作目录当作备用位置。

默认目录为 `~/.ky-learn`。用户可显式设置 `KY_LEARN_HOME`，但它必须展开为绝对路径。

## 默认读取层级

| 层级 | 内容 | 默认行为 |
|---|---|---|
| L0 | `learning-index.md` | 每次读取 |
| L1 | 当前 `subjects/<主题>.md` | 每次读取 |
| L2 | 当前主题明确关联的 `notes/` 文件 | 本次需要时读取 |
| L3 | 其他主题和历史笔记 | 只有溯源时读取 |

`learning-index.md` 保存 `active_subject_file`、`active_mentor`、`last_checkpoint` 和 `next_action`，用于新聊天中通过“继续学习”恢复。它不保存聊天窗口的活动状态。

## 保存门槛

满足以下至少一项才长期保存：

- 改变了原有理解或判断。
- 暴露了会反复出现的误区。
- 形成了可以在其他场景复用的方法。
- 产生了可靠的例子、反例或适用边界。
- 产生了明确的后续行动。

寒暄、确认、重复解释、普通可查询事实和未改变理解的中间推演默认不保存。

## 页面控制

- 默认每次只更新主题文件，不创建 Session 页面。
- 必须保留课程摘要时，每次最多创建一份整理后的 `notes/` 文件。
- 一次课程最多主动创建 3 个知识成果。
- 禁止保存完整聊天。
- 文件名使用安全字符，不包含用户设备绝对路径。
- 每完成一个稳定学习循环就更新检查点。
