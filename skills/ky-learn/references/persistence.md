# 学习沉淀协议

## 默认读取层级

开始任何读取或写入前，运行 `scripts/notes_root.py`。返回路径是本次操作唯一允许的笔记库。还没设置时问用户一次（见 `SKILL.md`）；不能写入时停止保存并说明原因；不得把当前工作目录当作备用位置。

| 层级 | 内容 | 默认行为 |
|---|---|---|
| L0 | `MOC_AI学习.md` | 每次读取 |
| L1 | 当前 `MOC_学习_<主题>.md` | 每次读取 |
| L2 | 相关概念卡、方法卡、原子卡 | MOC 明确关联或本次需要时读取 |
| L3 | 历史 Session、原始材料 | 只有溯源时读取 |

学习总览还保存 `active_subject`、`active_mentor`、`last_checkpoint` 和 `next_action`，用于新聊天中通过“继续学习”自动恢复。它不保存聊天窗口的活动状态；房间活动状态只由当前对话的未关闭标记决定。

## 保存门槛

满足以下至少一项才长期保存：

- 改变了原有理解或判断。
- 暴露了会反复出现的误区。
- 形成了可以在其他场景复用的方法。
- 产生了可靠的例子、反例或适用边界。
- 能发展为内容、项目或后续行动。

下列内容默认不保存：

- 寒暄、确认、重复解释。
- 可以随时重新查询的普通事实。
- 没有改变理解的中间推演。
- 只为完成当前步骤而产生的临时文本。

## 文件去向

- 学习总览：`30_MOCs/MOC_AI学习.md`（不存在时新建，只放 `active_subject`、`active_mentor`、`learning_preferences`、`last_checkpoint`、`next_action` 等字段和一行说明）
- 主题状态：`30_MOCs/MOC_学习_<主题>.md`
- 高信号课程摘要：`10_Source_Notes/15_Conversations/learning/`
- 概念、方法、判断：`20_Cards/`
- 内容机会：经用户确认后记成内容选题

## 页面控制

- 默认每次只更新主题 MOC，不创建 Session 页面。
- 必须保留课程摘要时，每次最多创建一份整理后的 Source Note。
- 一次课程最多主动创建 3 张卡片。
- 禁止把完整聊天复制到笔记库。
- 文件名不得包含设备非法字符；跨项目引用使用 `source_id`，不把脚本运行时返回的绝对路径写入笔记。
- 每完成一个稳定学习循环就更新检查点，不依赖用户主动说“保存”或“课程结束”。
