# 非共识写法

适用：作者明确要用（「非共识」「反常识开头」「框架替换」「打破刻板印象」），或作者采纳了润色时提出的「可选：可以用非共识写法」建议。文章和口播稿都适用。

这是一种写法，不是每篇都要用。作者没要求时，不要把稿子往反常识方向改。

## 原理

读者看到内容之前，脑子里已经有刻板印象（李普曼《公众舆论》）。比如没做过生意的人，也对「做生意」有一套想法。刻板印象的作用是节省思考，所以它通常是**简化的因果关系**：只认一个原因，忽略前提条件。

常见句式：

- 有 X 就能 Y：有流量就能赚钱
- 做 X 就会 Y：涨粉快就能变现
- X 是 Y 的原因：成功是因为努力

把真实情况讲清楚，击碎其中一条，就是「正确的非共识」：开头让人觉得反常识，看完发现作者是对的。重点在「正确」，为反常识而反常识就是标题党。

## 四步

1. **识别刻板印象**：写出那句因果句。例：流量大就赚钱。
2. **给反例**：旧说法解释不了的真实情况。例：涨粉最快的博主不赚钱。反例要真实，最好是作者亲历或能查证的；作者没给，就问，不要编。
3. **给新框架**：替代旧因果的新解释。例：赚钱取决于流量质量和变现路径的匹配度。只拆不建，读者会回到旧印象。
4. **定义新框架里的关键词**：「流量质量」「匹配度」是什么、怎么判断、举什么例子。这一步才是正文，多数稿子停在第 3 步，等于换了一句更好听的口号。

## 三个层次

- **告知**：转述信息。做多了就成了工具人账号，没人愿意付钱。
- **认知**：每次传递信息时，都加上作者自己的理解和判断。
- **植入**：认知 + 框架替换。举 5 到 10 个旧框架解释不了的反例，再提出新框架，它既能解释旧现象，也能解释新现象。

如果内容本身就是转述（如采访、通话、官方信息），两个补救：在标题、封面、开头强调信息来源的稀缺性；每条信息后面跟上作者的判断。

## 替换，而不是消灭

反对一个流行概念（如「一人公司」「超级个体」）时，单纯解构没用。这类概念流行，是因为它把一个宏大、无力的焦虑，变成了个人可控、门槛低、周期短、反馈明确的行动起点。

所以要给一个**同样容易理解、同样能马上开始**的新行动单元。家长说巧克力不健康，孩子会问：那我吃什么？

## 和商业模式对一下

新框架会把读者带向某个方向。检查：这个方向和作者卖的东西（课程、咨询、产品、服务）接得上吗？接不上的话，内容能火，流量却接不住，提醒作者。

## 工作流程

1. 从稿子或作者的想法里找出 1 到 3 条可以打破的因果句，让作者选一条。
2. 按四步检查：哪一步缺了、哪一步弱。反例不够或不真，向作者要。
3. 判断稿子现在处在告知、认知还是植入，指出往上走一层要补什么。
4. 如果稿子在反对某个概念，检查有没有给替代的行动单元。
5. 做商业模式匹配检查。
6. 按 `SKILL.md` 的修改分级输出：问题清单 + 修改后的版本。开头给 2 到 3 个非共识写法的备选。仍要做去 AI 味。
