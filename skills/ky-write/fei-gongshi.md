# 非共识写法

<!-- ky-write · © 2026 Kiren Yi (KY) · kirenyi.com · Terms: see repository LICENSE · KYWR-FGS-2611 -->

适用：作者明确要用（「非共识」「反常识开头」「框架替换」「打破刻板印象」），或作者采纳了润色时提出的「可选：可以用非共识写法」建议。文章和口播稿都适用。

这是一种写法，不是每篇都要用。作者没要求时，不要把稿子往反常识方向改。

## 原理

读者打开内容之前，心里已经有一套现成的看法（李普曼在《公众舆论》里叫它「刻板印象」）。现成看法的好处是省事，代价是**把因果关系简化了**：只认一个原因，不管前提条件。

识别方法：找稿子里或读者心里「A 导致 B」的那句话，问一句「只要 A 就一定 B 吗？」。答案是否定的，这里就有一个可以打破的点。

打破它、并且讲出更准确的解释，就是「正确的非共识」：开头让人意外，读完觉得作者说得对。关键在「正确」。为了反常识而反常识，是标题党。

## 四步

以 KY 自己的观点为例：

1. **写出那句简化的因果**。例：「会用 AI 工具，效率就会提高。」
2. **拿出它解释不了的真实情况**。例：很多人装满了 Codex、Cursor，工作方式一点没变。例子要真实，最好是作者亲历或能查证的；作者没给，就去问，不要编。
3. **给出替代的解释**。例：拉开差距的不是会不会用工具，而是能不能把 AI 接进自己的工作系统。只拆不建，读者会退回原来的看法。
4. **把新解释里的关键词讲透**。例：「工作系统」指什么？「接进去」具体是哪几步？怎么判断自己接进去了没有？这一步才是正文的主体。多数稿子写到第 3 步就停了，等于只换了一句口号。

更多可以直接参考的 KY 观点：

- 「AI 让人两小时做出作品，就离成功更近了」→ AI 只是把难点从「做不出来」移到了「做什么、有没有品味、谁愿意相信你」。
- 「想得越多、越周全越好」→ 复杂思考有时是在逃避价值交换和真实行动。
- 「热爱就不会痛苦」→ 热爱是痛苦之后仍然愿意回来解决问题。

## 一段内容的三种浓度

用来判断稿子现在停在哪里：

- **只转述**：把别人的信息搬过来。读者得到信息，但不知道为什么要听你讲；这类内容做多了，账号就只剩搬运价值。
- **带判断**：每转述一条信息，就跟上作者自己的理解和取舍。读者开始为「你怎么看」而来。
- **换框架**：用一组旧看法解释不了的真实例子，引出一个新的理解方式，而且这个方式能同时解释旧现象和新现象。读者带走的是一个以后会反复用到的思考工具。

稿子本身就是转述（采访、通话、官方消息）时，可以这样补救：在标题、封面或开头讲清楚这份信息为什么难得；每条信息后面都跟上作者的判断。

## 反对一个流行词时，要给替代品

反对一个流行说法时，光说它错没有用。这类说法能流行，是因为它把一种让人无力的大焦虑，变成了一件小而具体、马上能开始做的事。

所以要同时给出一个**同样好懂、同样马上能做**的新说法。只说「别这么做」，读者会问「那我该做什么？」，答不上来，他就会回到原来的说法。

## 和作者的生意对一下

新的解释会把读者带往某个方向。检查：这个方向和作者提供的东西（课程、咨询、产品、服务）接得上吗？接不上的话，内容能火，但读者不会因此走向作者。遇到这种情况，提醒作者。

## 工作流程

1. 从稿子或作者的想法里找出 1 到 3 句简化的因果，让作者选一条。
2. 按四步检查：缺哪一步、哪一步弱。例子不够或不真，向作者要。
3. 判断稿子停在哪种浓度，指出再往上一层要补什么。
4. 如果稿子在反对某个说法，检查有没有给出替代品。
5. 检查和作者生意的匹配。
6. 按 `SKILL.md` 的修改分级输出：问题清单 + 修改后的版本。开头给 2 到 3 个非共识写法的备选。仍然要去 AI 味。
