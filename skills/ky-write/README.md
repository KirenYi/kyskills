# ky-write

中文写作：商业/认知类观点文章、视频口播稿的写作辅助和润色。核心是去 AI 味：删垫词和黑话，检查观点和论证，保留作者自己的声音。

```text
/ky-write
```

```bash
./scripts/install-links.sh ky-write
```

## 五种用法

| 你给什么 | 得到什么 |
|----------|----------|
| 文章初稿 | 问题清单、精简后的版本（通常短 20% 到 30%）、修改对照 |
| 一个想法，还没成文 | 先问清核心观点、反对意见、真实案例，再帮你写 |
| 视频口播稿 | 一行一句的口播稿、预估时长、3 个前三秒开头备选 |
| 要英文字幕 | 中英逐句对照，每行不超过 42 个字符，避开英文 AI 腔 |
| 说「用非共识写法」 | 找出可打破的刻板印象，按「反例 → 新框架 → 定义关键词」改稿，给非共识开头备选 |

## 不会做的事

- 不编数字、案例或经历，缺了会问你
- 不把文章改得更"漂亮"，只改得更准、更短、更具体
- 不适用于文学散文
