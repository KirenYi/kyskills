# 英文字幕规则

适用：中文视频配英文字幕，或中文口播稿翻成英文。目标是让英语观众读起来像一个真人在说话，而不是 AI 翻译稿。

## 总原则

- 译意思，不译字。中文里的垫词、语气词直接不译。
- 口语、短句、主动语态。宁可简单，不要华丽。
- 保持作者的立场强度。中文说得很肯定，英文不要加 "might" "perhaps" 软化；中文有保留，英文也要保留。
- 不添加原文没有的信息、解释或总结。

## 英文 AI 腔黑名单

遇到以下词或句式，换成更普通的说法或直接删：

| 避免 | 替代 |
|---|---|
| delve into | look at / get into |
| crucial / pivotal / vital | key / important / 或直接删 |
| landscape (the e-commerce landscape) | e-commerce / the market |
| leverage (动词) | use |
| navigate (the challenges) | deal with / handle |
| robust / seamless / cutting-edge | 删掉，或说具体好在哪 |
| unlock / unleash (potential) | get / make the most of |
| game-changer / revolutionize | 说具体改变了什么 |
| foster / empower | help / let |
| a testament to | shows |
| ever-evolving / fast-paced | 删掉 |
| In today's ... world | 删掉，直接开始 |
| It's worth noting that / It's important to note that | 删掉，直接说 |
| Let's dive in / Let's explore | 删掉，或 "Here's the thing" |
| In conclusion / Ultimately / At the end of the day | 删掉 |
| Not only ... but also ... | 拆成两句 |
| It's not just X, it's Y | 只在原文真有对比时用，全片不超过一次 |

另外避免：

- 一句话里三个并列形容词（"powerful, flexible, and intuitive"）。
- 每段结尾都升华一句。
- 过多破折号（—）。字幕里基本不用。

## 字幕格式

- 每行不超过 42 个字符，每屏最多两行。
- 按意群断行，不在冠词、介词、助动词后面断：
  - ✗ "I lost thirty thousand on a / product last month"
  - ✓ "I lost thirty thousand / on a product last month"
- 一屏字幕对应一句中文，时间轴和中文对齐；英文太长时压缩意思，不要硬塞。
- 数字：一到十用英文单词，其余用阿拉伯数字；金额写明币种（"30,000 yuan" / "$4,000"），不确定币种时问作者。

## 中文特有表达的处理

- 网络用语、行业黑话（"卷""割韭菜""打法""闭环"）：译出它实际指的意思，不要直译。
  - "卷"→ "everyone's competing harder for the same thing"（按语境缩短）
  - "割韭菜"→ "taking advantage of beginners" / "fleecing newcomers"
- 成语、俗语：译意思，不找对应的英文谚语，除非非常贴切。
- 专有名词（平台名、品牌、工具名）保持原名：Temu, Shopify, TikTok Shop, Claude Code。中国平台首次出现可以加简短说明："Xiaohongshu (RedNote)"。

## 工作流程

1. 先通读中文，确认每句的意思和语气强度。
2. 逐句翻译，按上面的格式断行。
3. 用黑名单扫一遍。
4. 出声读英文，不像人说话的句子重写。
5. 输出时把中文和英文逐句对照，存疑的地方标出来问作者，不要自己猜。
