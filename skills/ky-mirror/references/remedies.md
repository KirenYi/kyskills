# 常见感受与对应做法

第二步第 3、5 条使用。先猜感受，请用户确认，再按感受选做法。一件事可能同时有两种感受，按最强的那个选。

| 感受 | 心里的话（举例） | 最小行动往哪个方向 |
|---|---|---|
| 不知道从哪开始 | 「不知道从哪下手」 | 拆到下一个具体的动作：不是「做调研」，是「打开表格，写下 5 个同行的名字」。模糊本身就让人想躲，清楚了阻力会小很多。 |
| 怕被评价、怕失败 | 「别人会觉得我很业余」「做了也不一定成」 | 降低这一次的分量：把它定成一次测试，写清只验证一件事。测试失败说明「这个做法不行」，不说明「我不行」。 |
| 怕不够好 | 「还不够好，不能拿出去」 | 先定「够用」的标准和时间上限，比如「一小时内做出六十分的版本」，允许初稿很糟。 |
| 无聊、没意义 | 「这事太烦了」 | 重新连到他在乎的目标；或者把它和一件喜欢的事绑在一起（只在做这件事时听喜欢的播客）。 |
| 抗拒、不服气 | 「凭什么要我来做」 | 先问这件事是不是真该他做。该做，就让他自己决定怎么做；不该做，就交出去或明确放下。 |
| 怕看到坏消息 | 「我不想看数据」 | 不靠当下的意愿：定一个固定时间去看，比如每周一上午十点，变成例行的事。 |
| 怕承认失败 | 「再坚持一下也许就好了」 | 写下「到哪天、看到什么就停」；或者问「如果今天从零开始，还会投入吗」。事先定好的线，让「停」从一个情绪决定变成照着执行。 |

## 可以叠加的通用做法

每次最多加一个，不要堆。

- **只承诺开始**：只做五分钟，之后想停就停。真开始做，通常没有想象中难受。
- **如果……就……**：「如果早上打开电脑，就先发三条客户消息」。提前做好决定，到时候不用再和情绪讨价还价。
- **带着感受去做**：不用等焦虑消失。可以对自己说「我注意到我有一个『这会失败』的念头」，念头不等于事实。
- **不责备自己**：原谅上一次拖延，比责备自己更能减少下一次。
- **改环境**：手机放到另一个房间，只开一个页面，让躲开变得麻烦。
- **对外承诺**：告诉一个人，或者定一个对外的截止时间。
