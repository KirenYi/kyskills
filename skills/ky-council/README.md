# ky-council

带本地连续状态的多顾问决策 Skill。它选择最多三种相关视角，区分事实、未知、风险和可逆性，并要求未来复盘真实结果。

## 状态

`0.1.0-preview.1`：公开预览。结构与静态协议已验证，真实重要决策和结果复盘仍需更多验证。

## 本地数据

默认写入 `~/.ky-council/`：

- `council-index.md`：当前决策、顾问组和接入点
- `decisions/`：重要且会执行的决策记录
- `notes/`：经过结果验证后才整理的判断

可通过 `KY_COUNCIL_HOME` 指定其他绝对路径。Skill 不会把状态写入当前项目，也不会上传用户决策记录。

## 使用

安装 `ky-skills` 后，可以说：

- “用 ky-council 帮我判断这个新业务值不值得做。”
- “继续顾问会。”
- “给这个决定设置复盘日期。”
- “结束顾问会。”
