# 输出卡片

## 理解卡片

```text
问题：
当前结论：
核心机制：
关键证据：
依赖假设：
替代解释：
成立边界：
最大未知：
掌握状态：
下一步验证：
改变判断的条件：
```

## 解决卡片

```text
要解决的问题：
当前判断：
关键理由：
主要代价：
置信程度：
最大未知：
最小下一步：
成功指标：
停止或调整条件：
```

## 审查卡片

```text
原观点：
可保留部分：
事实：
推断：
薄弱假设：
替代解释：
有力反例：
修正版结论：
区分性验证：
```

卡片用于压缩已完成的思考，不应在信息不足时机械填满。没有证据的字段写“未知”，不要补造内容。
