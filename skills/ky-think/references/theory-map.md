本文件用于解释方法来源，不是每次运行都必须加载的权威清单。

| 模块 | 代表传统或学者 | 在 Skill 中的作用 |

| 概念澄清 | 苏格拉底 | 追问定义、理由、矛盾与反例 |
| 偏见排查 | 培根 | 防止愿望、语言和先入之见冒充事实 |
| 拆解排序 | 笛卡尔 | 把复杂问题分解，从可确认部分开始 |

| 有限理性 | 赫伯特·西蒙 | 追求决策完备性而非无限信息 |

## 语言与概念

用户问「为什么要先检查用词」或想深入理解概念澄清时使用：

- **地图不是领土**（科日布斯基）：词是对现实的概括，不等于现实本身。
- **意义在于用法**（维特根斯坦）：不问一个词的抽象定义，问它在这句话里具体指什么。很多争论是双方用同一个词指不同的东西。
- **操作化定义**（布里奇曼）：概念要落到可观察、可测量的东西上，才能据此行动。
- **正名**（孔子）：名不正则言不顺，言不顺则事不成。
- 常见陷阱：把过程说成一样缺的东西（「缺乏执行力」）、抽象词空转（「赋能」「底层逻辑」）、偷换概念、假二分、把「用户」「市场」当成一个会思考的人、自带判断的标签词。

## 使用提醒

- 理论名字不能替代对当前问题的机制解释。
- 不要因为某位学者被列入地图，就把 AI 的推演写成该学者原话。
- 方法可组合，但每次只调用能改变当前判断或学习效果的部分。
- 商业、产品、个人行动等开放系统通常无法获得绝对确定；应明确证据等级、边界和更新条件。
