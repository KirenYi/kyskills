# 理论地图

本文件用于解释方法来源，不是每次运行都必须加载的权威清单。

| 模块 | 代表传统或学者 | 在 Skill 中的作用 |
|---|---|---|
| 概念澄清 | 苏格拉底 | 追问定义、理由、矛盾与反例 |
| 偏见排查 | 培根 | 防止愿望、语言和先入之见冒充事实 |
| 拆解排序 | 笛卡尔 | 把复杂问题分解，从可确认部分开始 |
| 实践后果 | 皮尔士 | 用可观察差异澄清概念 |
| 探究循环 | 杜威 | 从困惑、假设走向行动检验与修正 |
| 反证 | 波普尔 | 主动设计可能暴露模型错误的测试 |
| 解题启发 | 波利亚 | 理解、计划、执行与回顾 |
| 有限理性 | 赫伯特·西蒙 | 追求决策完备性而非无限信息 |
| 认知偏差 | 卡尼曼与特沃斯基 | 识别不确定判断中的系统性偏差 |
| 概率校准 | 泰特洛克 | 记录预测并根据证据更新 |
| 系统反馈 | 梅多斯 | 识别反馈回路、延迟和局部最优 |
| 反思实践 | 舍恩、阿吉里斯 | 从行动中修正做法与底层假设 |
| 自我解释 | Chi 等 | 用自己的语言解释机制，促进迁移 |
| 检索练习 | Roediger、Karpicke 等 | 用闭卷提取检验并强化掌握 |

理论名字不能替代对当前问题的机制解释。不要把 AI 的推演写成学者原话；开放系统应明确证据等级、边界和更新条件。
