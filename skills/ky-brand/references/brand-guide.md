# 视觉风格指南

> 默认主题 A · 杂志（magazine）。B · 书房（study）、C · 暖光（warm）作为备选。

## 1. 一句话气质

**像一本印刷精良的杂志：克制、留白多，用一抹红说重点。**
观点先行，文字就是视觉，不靠装饰。

## 2. 色彩（magazine）

| 角色 | 色值 | 用法 |
|---|---|---|
| 底色 | `#F7F5F0` 米白 | 所有浅色物料的背景 |
| 主文字 | `#111111` 墨黑 | 标题、正文；深色海报的底色 |
| 强调 | `#D23C22` 红 | **一张图只强调一处**：一个词、一条短线、一个编号 |
| 深底强调 | `#FF5A3C` 亮红 | 深色背景上的强调和按钮 |
| 辅助 | `#6B665F` 暖灰 | 副标题、说明、页眉页脚 |

禁止：大面积红色铺底；同一张图出现两种以上强调色；冷蓝灰科技色。

## 3. 字体

- 标题：**思源宋体 Noto Serif SC**，粗（900）
- 正文、标签：**思源黑体 Noto Sans SC**
- 编号、引号：思源宋体斜体，红色
- 两款都是 OFL 开源许可，可商用。不要换成其他未授权字体。

## 4. 版式规则

- 左对齐，大留白；四边留白不少于画面短边的 8%。
- 结构固定为四层，从上到下：小标签（kicker，红短线 + 字距加宽的小字）→ 大标题 → 红色短横线 → 署名。
- 署名（用户设置的名字 + 网址）放在每张图的左下或右下。用户选择不署名时省略。
- 例外：公众号、小红书（`wechat-cover`、`wechat-square`、`xhs`）带网址容易被判引流，署名默认只留名字。
- 有照片时：人像放右侧或底部，用米白渐变过渡；文字和人脸分区，文字绝不压脸。
- PPT：页眉写"课程名 · 第 N 讲"和页码，页脚写署名；封面页和结束页用深色底。

## 5. 文案规则

- 标题 ≤ 2 行、每行 ≤ 9 个字（竖版 ≤ 6 个字）。
- 只给一个词标红，挑最反常识、最有冲突的那个词。
- **封面只抛问题，不给答案**：可以用 `{？？}` 红框制造悬念，答案留给正文。
- 讲 AI / 工具的主题时，标题里要出现读者在意的关键词（AI、Claude、Codex、工作流）。
- 不用感叹号堆砌，不用"震惊""必看"这类词。

## 6. 三套主题对照

| | A · 杂志（默认） | B · 书房 | C · 暖光 |
|---|---|---|---|
| 底色 / 强调 | 米白 / 红 | 暖白 / 墨绿（辅色赭红） | 沙色 / 焦糖（辅色哑光绿） |
| 标题字体 | 思源宋体 900 | 思源黑体 800 | 思源宋体 700 |
| 特点 | 锐利、有态度，和 ky-video 同款 | 安静专业 | 温暖松弛，带轻微颗粒感 |
| 适合 | 观点、AI、课程，默认都用它 | 偏知识型的长文 | 生活感、个人随笔 |

样板图：`assets/samples/magazine.png`、`study.png`、`warm.png`

## 7. 修改风格时

改色值或字体：同时改 `assets/themes/*.json`、本文件，以及 `ky-video/assets/styles/magazine/`（视频风格包），保持文章、视频、课程三处一致。
