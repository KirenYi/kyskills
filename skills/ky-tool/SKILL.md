# ky-tool

判断一个 AI 工具是否真的创造价值，而不是复述宣传页或放大第一次成功。

## 先定义决策

1. 写清要判断的工具、具体任务和使用者。
2. 写清待做决定：试用、购买、续费、替换、扩大使用或停止。
3. 选择一个真实、可重复、能在合理时间内完成的标准任务。
4. 固定输入、完成标准、质量标准、设备、版本和测试环境。
5. 对人工基线和 AI 工具使用相同输入与相同验收标准。

不要用功能演示、宣传数据或不同难度的任务代替公平对照。

## 建立人工基线

在不使用待测工具的情况下完成标准任务，并记录：

- 开始时间、结束时间和总耗时；
- 直接费用及其计算方式；
- 一次通过率、错误、遗漏和返工；
- 最终质量与必须由人完成的判断；
- 可复核证据，如原始文件、输出文件、日志或截图。

若没有可靠的人工基线，停止下最终结论，把补测人工基线列为第一步。

## 测试 AI 工具

使用同一标准任务至少测试 3 次。每次分别记录：

| 项目 | 记录内容 |
|---|---|
| 设置 | 安装、配置、提示、素材整理与权限准备 |
| 学习 | 为完成任务新增的学习时间 |
| 运行 | 工具实际处理时间 |
| 等待 | 排队、上传、下载、生成与重试时间 |
| 纠错 | 检查、修正错误和补全遗漏的时间 |
| 返工 | 重做失败步骤或回退人工流程的时间 |
| 集成 | 导出、格式转换和接入后续流程的时间 |
| 费用 | 订阅、点数、API、算力和其他增量成本 |
| 质量 | 正确项、错误项、遗漏项与必须人工判断项 |
| 证据 | 输入、输出、日志、截图或账单依据 |

按以下口径计算每次总成本：

- `总耗时 = 设置 + 学习 + 运行 + 等待 + 纠错 + 返工 + 集成`
- `总费用 = 工具增量费用 + 人工时间成本 + 失败造成的可确认损失`

不要只报告生成时间。不要把未发生或无法确认的损失填成确定数字。

## 比较价值

使用同一把尺比较人工基线与 3 次 AI 测试：

1. 比较总耗时，而非单次运行速度。
2. 比较最终质量、一致性、错误类型和遗漏类型。
3. 比较总费用、学习成本与后续维护成本。
4. 判断它是在节省时间、提高质量，还是创造人工原本做不到的能力。
5. 检查 3 次结果的波动、失败率和对提示或环境的敏感度。
6. 标出仍必须由人承担的判断、审核和责任。

只根据可见证据计算差值。数据口径不一致时，先统一口径再比较。
不要自行设置数值化的通过门槛。只使用用户给出的质量容忍度、预算、月任务量和时间价值，或展示计算公式让用户决定；缺少这些信息时保留为未知。

## 检查风险

逐项判断并说明证据或未知项：

- 敏感数据是否上传、存储、训练或被第三方访问；
- 输入和输出是否存在版权、许可、署名或商用限制；
- 使用方式是否可能违反平台规则或带来账号风险；
- 输出错误是否会造成安全、法律、财务或声誉损失；
- 流程是否过度依赖单一供应商、格式或在线服务；
- 失败时是否能回退到人工流程并保留原始材料。

高风险且证据不清时，不给出无条件推荐。

## 处理证据不足

缺少人工基线、少于 3 次可比测试、没有质量标准或关键风险未知时：

1. 明确标记 `证据不足`。
2. 列出已有事实、合理推断和未知项，避免混写。
3. 输出最小测试计划，包括任务、固定输入、指标、证据和 3 次复测安排。
4. 允许给出暂定倾向，但不要冒充最终结论。
5. 不发明耗时、成本、成功率、质量分数或风险事实。
